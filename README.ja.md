# Ririku

**Mac のノッチに、同期歌詞と音楽コントロールを。**

[English](README.md) · [Bahasa Indonesia](README.id.md) · 日本語

> v0.3.1 の英語版 README を翻訳したものです。内容に違いがある場合は英語版が優先されます。

Ririku(リリク、「lyric」から)は、Chromium 系ブラウザの YouTube や YouTube Music で再生中の曲をノッチのすぐ下に表示する、無料のオープンソース macOS アプリです。再生/一時停止、曲送り、シーク、1 行ずつ同期する歌詞に対応しています。SwiftUI/AppKit によるネイティブアプリと小さなブラウザ拡張機能で構成され、アカウントもテレメトリもありません。

> **ステータス:** 初期プロトタイプ(v0.3.1)。まだリリースは公開されていないため、現時点では[ソースからビルド](docs/development/README.md)する必要があります。Apple Music と Spotify は対応予定ですが、まだ使えません。

## 機能

- **ノッチパネル:** コンパクトなアイランドにアートワーク、装飾用スペクトラム、最大 3 行の歌詞を表示。ポインタを合わせるかクリックすると、曲情報、再生位置のバー、操作ボタンが表示されます。
- **同期歌詞:** 曲名、アーティスト、再生時間をもとに [LRCLIB](https://lrclib.net) から自動で検索し、Mac にキャッシュします。動画の字幕を使う、別バージョンの歌詞を選ぶ、曲ごとにタイミングを調整する、手元の `.lrc` ファイルを読み込むこともできます。
- **日本語の歌詞に配慮:** 歌詞ファイルに日本語とローマ字が同じタイムスタンプで入っている場合、日本語の行だけを表示できます。
- **再生中のプレーヤーに追従:** 再生を始めたブラウザのタブに自動で切り替わります。1 つのタブに固定することもできます。
- **カスタマイズ:** アイランドの幅、歌詞の行数、アクセントカラー、アニメーション、「視差効果を減らす」への対応。
- **表示言語:** English、Bahasa Indonesia、日本語。macOS の言語に合わせるか、セットアップで選べます。
- **ログイン時に起動(任意):** セットアップのスイッチ 1 つで設定でき、初期設定はオフです。

## 動作環境

- macOS 14 Sonoma 以降。Apple シリコンで開発しており、Intel Mac は未検証です。
- ノッチのある MacBook を推奨します。その他のディスプレイではメイン画面を使いますが、十分に検証されていません。
- YouTube(`www.youtube.com`)または YouTube Music(`music.youtube.com`)を開いた Chromium 系ブラウザ(Chrome、Brave、Edge、Vivaldi、Opera、Chromium、Arc)。検証済みは Chrome のみで、Safari と Firefox には未対応です。

## インストール

Ririku は無料で、Apple の公証を受けていません(公証には有料のデベロッパーアカウントが必要です)。そのため初回起動時に macOS で確認が必要です。詳しい手順は[ユーザーガイド](docs/user-guide.ja.md#インストール)を参照してください。

1. **アプリを入手する。** 公開後に [Releases](https://github.com/ghufronakbar/Ririku/releases) から `Ririku.zip` をダウンロードして展開し、**Ririku.app** を「アプリケーション」フォルダに移動します。最初のリリースまでは[ソースからビルド](docs/development/README.md)してください。
2. **起動を許可する。** Ririku を開きます。ブロックされた場合は **システム設定 → プライバシーとセキュリティ** を開いて下にスクロールし、**このまま開く** をクリックします。
3. **ブラウザと接続する。** Ririku の **セットアップ** が開きます。**ブラウザとの接続** の 4 つの手順に従います: **登録**、**Finder に表示**、ブラウザの拡張機能ページで **デベロッパー モード** をオンにして **パッケージ化されていない拡張機能を読み込む** からそのフォルダを選択、最後に YouTube のタブを再読み込みします。

そのブラウザで曲を再生し、ノッチにポインタを合わせてみてください。

## 使い方

- **パネルを開く:** ノッチにポインタを合わせる、アイランドをクリックする、またはメニューバーの波形アイコンから **音楽パネルを開く** を選びます。Esc キーで閉じます。
- **セットアップ:** 展開したパネルの歯車ボタン、またはメニューバーのアイコンの **セットアップ…** から開きます。
- **歌詞がずれる場合:** **セットアップ → 歌詞** でこの曲のオフセットを調整するか、**歌詞のバージョンを検索して選択** で再生時間が合うバージョンを選びます。
- **手元に音楽がない場合:** **セットアップ → プロトタイプ → ローカルデモ** をオンにすると、ブラウザなしでパネルを試せます。

すべての設定、トラブルシューティング、アップデート、アンインストールについては[ユーザーガイド](docs/user-guide.ja.md)を参照してください。

## プライバシー

Ririku にはアカウントがなく、分析データも送信しません。歌詞の自動検索がオンのときは、曲名、アーティスト、再生時間を LRCLIB に送信します。サムネイルは YouTube/Google の画像サーバーから取得します。拡張機能は YouTube と YouTube Music でのみ動作してページ上のプレーヤーを読み取り、Cookie や閲覧履歴は読み取りません。詳しくはユーザーガイドの[プライバシー](docs/user-guide.ja.md#プライバシー)を参照してください。

歌詞は LRCLIB から取得しており、有無やタイミングは保証されません。Ririku は歌詞をローカルキャッシュにのみ保存し、音声や動画はダウンロードしません。
