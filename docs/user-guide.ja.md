## 始める前に

必要なもの:

- **macOS 14 Sonoma 以降**の Mac。Apple シリコンで開発しており、Intel Mac は未検証です。
- **ノッチ**のある MacBook を推奨します。その他のディスプレイではメイン画面の上部に表示されますが、十分に検証されていません。
- **YouTube** または **YouTube Music** で音楽を再生している **Google Chrome**。Safari、Brave、Apple Music、Spotify などには未対応です。

## インストール

### 1. Ririku をダウンロードする

[Releases ページ](https://github.com/ghufronakbar/Ririku/releases)から `Ririku.zip` をダウンロードし、ダブルクリックして展開します。まだ最初のリリースは公開されていません。それまでは[ソースからビルド](development/README.md)する必要があります。

**開く前に** **Ririku.app** を「アプリケーション」フォルダに移動してください。「ダウンロード」から直接開くと、macOS が一時的な場所から実行するため、Chrome と接続できません。

### 2. 初めて Ririku を開く

Ririku は無料で、Apple の公証(ノータリゼーション)を受けていません。公証には有料の Apple デベロッパーアカウントが必要なためです。そのため、初回起動時に macOS がブロックします。表示される文言は macOS のバージョンによって異なります。

**macOS 15 Sequoia 以降**

1. 「アプリケーション」で **Ririku** をダブルクリックします。検証できないという警告が表示されたら **完了** をクリックします(ゴミ箱には入れないでください)。
2. **システム設定 → プライバシーとセキュリティ** を開き、「セキュリティ」までスクロールします。
3. Ririku がブロックされたというメッセージの横にある **このまま開く** をクリックし、パスワードまたは Touch ID で確認してから **開く** をクリックします。

**macOS 14 Sonoma**

1. 「アプリケーション」で **Ririku** を Control キーを押しながらクリック(または右クリック)し、**開く** を選びます。
2. ダイアログで **開く** をクリックします。

この操作はダウンロードしたバージョンごとに一度だけ必要です。

> **上級者向け:** ダウンロードしたファイルを信頼できる場合は、ターミナルで `xattr -dr com.apple.quarantine /Applications/Ririku.app` を実行する方法もあります。

Ririku は Dock に表示されません。メニューバーの**波形**アイコンから使います。初回起動時には**セットアップ**ウインドウが開きます。

### 3. Chrome と接続する

Ririku は付属の小さな拡張機能を通じて Chrome の YouTube プレーヤーを読み取ります。**セットアップ → Chrome との接続** で、次の 4 つの手順を一度だけ行います。完了した手順には緑のチェックマークが付きます。

1. **Chrome との接続を登録** → **登録** をクリックします。この Ririku と Chrome が通信できるようになります。
2. **拡張機能のフォルダをコピー** → **Finder に表示** をクリックします。拡張機能が `~/Library/Application Support/Ririku/Chrome Extension` にコピーされ、Finder に表示されます。
3. **Chrome で拡張機能を読み込む** → **アドレスをコピー** をクリックし、Chrome のアドレスバーに `chrome://extensions` を貼り付けて Return キーを押します。続いて:
   - 右上の **デベロッパー モード** をオンにします。
   - **パッケージ化されていない拡張機能を読み込む** をクリックし、手順 2 の **Chrome Extension** フォルダを選択します。
4. **接続を確認** → すでに開いている YouTube または YouTube Music のタブを再読み込みします。この手順が緑になり、拡張機能のバージョンが表示されます。

Chrome で曲を再生し、ノッチにポインタを合わせてみてください。

**デベロッパー モード**はオンのままにしてください。Chrome ウェブストア以外の拡張機能を使うために必要です。

## パネルの使い方

- **コンパクト表示:** 再生中はノッチの左にアートワーク、右に装飾用のスペクトラムが表示されます。歌詞がある場合はその下に歌詞の行が表示されます。スペクトラムはアニメーションのみで、一時停止中は平らになり、音声は解析しません。
- **展開:** ノッチにポインタを合わせるか、アイランドをクリックします。メニューバーのアイコンから **音楽パネルを開く** を選ぶこともできます。
- **操作:** 曲名、アーティスト、ソース、**セットアップ**を開く歯車ボタン、再生位置のバー、前へ・再生/一時停止・次へのボタンがあります。サイトが提供していない操作のボタンは無効になります。ライブ配信では **ライブ** と表示され、シークできません。
- **閉じる:** ポインタを離すか **Esc** キーを押します。
- **広告:** YouTube で広告が流れている間は、操作が無効になり歌詞も止まります。
- **歌詞がない場合:** アイランドはコンパクトなまま、**歌詞が見つかりません** と短く表示されます。詳細は **セットアップ → 歌詞** で確認できます。

終了するには、メニューバーのアイコンから **Ririku を終了** を選びます。

## セットアップ

展開したパネルの歯車ボタン、またはメニューバーのアイコンの **セットアップ…** から開きます。変更はすぐに反映されます。

### 言語

**表示言語:** **システムに従う**(初期設定)、English、Bahasa Indonesia、日本語。「システムに従う」では **システム設定 → 一般 → 言語と地域** の中で最初に対応している言語を使い、なければ English になります。曲名、歌詞、字幕、macOS やウェブサイトからのメッセージは元の言語のまま表示されます。

### Chrome との接続

上記の 4 つのインストール手順です。Ririku をアップデートしたときや別のフォルダに移動したときは、ここを確認してください。

### 起動

**ログイン時に Ririku を開く**(初期設定でオフ): ログイン後に Ririku がバックグラウンドで起動します。Dock アイコンもウインドウも表示されません。初回は macOS が許可を求めることがあります。セットアップに承認待ちと表示された場合は、**ログイン項目の設定を開く** をクリックし、そこで Ririku をオンにしてください。Ririku を一時的な場所から実行している間はこのスイッチを使えないため、先に **アプリケーション** に移動してください。**システム設定 → 一般 → ログイン項目** からオフにすることもできます。

### 音楽ソース

- **再生中のプレーヤーに自動で追従**(初期設定でオン): 再生を始めた Chrome のタブに追従します。
- **使用するプレーヤー:** 自動モードをオフにすると、1 つのタブに固定できます。ページを再読み込みしても同じタブに再接続します。

### 外観

- **コンパクト表示の幅**(280–620 pt、初期値 360)と**展開表示の幅**(360–720 pt、初期値 442)。パネルがノッチより狭くなることはありません。**サイズをリセット** で初期値に戻ります。
- **アクセントカラー:** ピーチ、ラベンダー、ニュートラル。
- **パネルを滑らかに切り替える:** オフにするとサイズがすぐに変わります。macOS の **視差効果を減らす** がオンの場合も、アニメーションとスペクトラムは止まります。
- **アイランドに歌詞を表示** と **歌詞の行数:** 1(現在の行)、2(現在 + 次)、3(前 + 現在 + 次)。

### 歌詞

- **同じタイムスタンプでは日本語を優先**(初期設定でオン): [日本語の歌詞](#日本語の歌詞)を参照してください。
- **歌詞のソース:**
  - **自動 · LRCLIB、次に字幕:** LRCLIB のタイムスタンプ付き歌詞を使い、見つからず動画の字幕(CC)がオンの場合は字幕を表示します。
  - **LRCLIB / LRC のみ:** 字幕は表示しません。
  - **YouTube 字幕のみ:** プレーヤーの字幕だけを表示し、LRCLIB には接続しません。
- **曲が変わったら LRCLIB を自動検索**(初期設定でオン)。
- **自動の結果に戻す:** この曲の手動選択を解除し、LRCLIB で再検索します。
- **LRC を読み込む…:** 手元の `.lrc` ファイル(UTF-8、1 MB まで)を、Ririku を終了するまで現在の曲に使います。
- **この曲のオフセット** と **0.1 秒早める/遅らせる:** [タイミングを直す](#タイミングを直す)を参照してください。
- **歌詞のバージョンを検索して選択:** [別のバージョンを選ぶ](#別のバージョンを選ぶ)を参照してください。

### プロトタイプ

**ローカルデモ(音声なし)** をオンにすると、Chrome なしでサンプル曲を使ってパネルを試せます。実際の音楽を使う前にオフにしてください。

## 歌詞をより良く表示する

Ririku は無料のコミュニティデータベース [LRCLIB](https://lrclib.net) で、曲名、アーティスト、再生時間をもとに歌詞を検索します。曲名とアーティストが一致し、再生時間の差が 3 秒以内の場合だけ自動で採用します。すべての曲の歌詞があるとは限らず、タイミングは登録された音源によって異なります。

### タイミングを直す

すべての行が同じだけ早い、または遅い場合は、**セットアップ → 歌詞** の **この曲のオフセット** を使います。正の値で歌詞を遅らせ、負の値で早めます。オフセットは動画ごとに保存され、次に同じ曲を再生したときにも適用されます。字幕には適用されません。

### 別のバージョンを選ぶ

歌詞がだんだんずれる、別バージョンのもの、または見つからない場合は、**歌詞のバージョンを検索して選択** を開きます。曲名、アーティスト、別名(日本語や英語のタイトルなど)を入力して **検索** をクリックします。結果はプレーヤーの再生時間に近い順に並びます。差が 3 秒を超えるものには **バージョンを確認** と表示され、イントロ、ライブ、カバーなど別の音源の可能性があります。**使用** をクリックすると適用されます。選択は Ririku を終了するまで有効です。

### 字幕

YouTube に字幕がある場合は、プレーヤーの **CC** をオンにします。タイムスタンプ付きの歌詞がないときに字幕を表示するほか、**YouTube 字幕のみ** では常に字幕を表示します。映像に焼き込まれた字幕は読み取れません。

### 日本語の歌詞

LRCLIB の歌詞ファイルには、日本語の行とローマ字の行が同じタイムスタンプで並んでいるものがあります。**同じタイムスタンプでは日本語を優先** がオンの場合、日本語の行とまったく同じタイムスタンプを持つラテン文字だけの行を表示しません。別の時刻の行や複数の言語が混ざった行はそのまま表示され、ファイルから削除されることはありません。二か国語のデュエットなど、すべての行を表示したい場合はオフにしてください。

## アップデート

1. メニューバーのアイコンから Ririku を終了します。
2. 「アプリケーション」の **Ririku.app** を新しいバージョンに置き換えて開きます。再度 **このまま開く** が必要になる場合があります。
3. **セットアップ → Chrome との接続** で緑でなくなった手順がある場合は、**Finder に表示** をクリックして新しい拡張機能をコピーし、`chrome://extensions` で拡張機能の **再読み込み** ボタンをクリックしてから YouTube のタブを再読み込みします。

Ririku を別のフォルダに移動した場合は、手順 1 の **再登録** をクリックします。

## トラブルシューティング

**「登録」ボタンが無効、またはオレンジ色の警告が表示される。** Ririku が一時的な場所から実行されています。終了して **Ririku.app** を「アプリケーション」に移動し、もう一度開いてください。

**手順 4 に「未接続です」と表示される。**
- Ririku が起動していること(メニューバーのアイコン)と、Chrome が開いていることを確認します。
- `chrome://extensions` で **デベロッパー モード** がオンで、**Ririku — Chrome Bridge** が有効になっていることを確認します。
- YouTube または YouTube Music のタブを再読み込みし、再生を始めます。
- Chrome の拡張機能アイコンをクリックすると状態が表示されます。**今すぐ接続を試す** で再試行、**アプリのセットアップを開く** で Ririku を開けます。
- 拡張機能は 1 つだけ読み込んでください。重複している場合は `chrome://extensions` で削除します。
- 同時に接続できる Chrome プロファイルは 1 つだけです。

**拡張機能のアイコンに「!」が表示される。** 拡張機能が Ririku に接続できていません。Ririku を開き、**セットアップ → Chrome との接続** を完了してください。

**「別の場所にある Ririku 用に登録されています」と表示される。** アプリが移動されたか、別のコピーが登録されています。**再登録** をクリックします。

**拡張機能が古い。** 手順 2 の **Finder に表示** をクリックし、`chrome://extensions` で拡張機能の再読み込みボタンをクリックします。

**歌詞が見つからない。** LRCLIB にその曲がないか、動画タイトルが曲名と異なる可能性があります。[別のバージョンを選ぶ](#別のバージョンを選ぶ)、字幕、または **LRC を読み込む…** を試してください。

**歌詞が普通のテキストで表示され、現在の行が強調されない。** タイミング情報のない歌詞しか見つかりませんでした。別のバージョンを試してください。

**「前へ」または「次へ」が無効になっている。** プレイリストのない単独の動画など、ページにそのボタンがありません。

**「別の Ririku がすでに起動しています」と表示される。** もう一方の Ririku を終了してください。

**YouTube の変更で動かなくなった。** Ririku は YouTube のページを読み取るため、ページの変更で動作しなくなることがあります。[Issue を作成](https://github.com/ghufronakbar/Ririku/issues)してください。

## アンインストール

1. メニューバーのアイコンから Ririku を終了します。
2. `chrome://extensions` で **Ririku — Chrome Bridge** を削除します。
3. **Ririku.app** をゴミ箱に入れます。
4. 必要に応じてデータを削除します。Finder で **移動 → フォルダへ移動…** を選び、次の項目だけを削除してください:
   - `~/Library/Application Support/Ririku`
   - `~/Library/Application Support/Google/Chrome/NativeMessagingHosts/io.github.lanstheprodigy.ririku.bridge.json`
   - `~/Library/Caches/io.github.lanstheprodigy.ririku`
   - `~/Library/Preferences/io.github.lanstheprodigy.ririku.plist`(またはターミナルで `defaults delete io.github.lanstheprodigy.ririku` を実行)

## プライバシー

- **アカウントも分析もありません。** Ririku は利用データを収集しません。
- **LRCLIB:** 自動検索がオンのとき、曲名、アーティスト、再生時間を `lrclib.net` に送信します。**検索** では入力した文字列を送信します。**YouTube 字幕のみ** モードでは LRCLIB に接続しません。
- **アートワーク:** サムネイルは YouTube/Google の画像サーバーから取得します。
- **Chrome 拡張機能:** `www.youtube.com` と `music.youtube.com` でのみ動作し、`nativeMessaging` 権限だけを使います。ページ上のプレーヤーの状態、曲名、アーティスト、アートワークのアドレス、表示中の字幕を読み取り、Mac 上の Ririku アプリにだけ送信します。Cookie、パスワード、閲覧履歴は読み取りません。
- **Mac に保存されるもの:** 見つかった歌詞は 30 日間(最大 300 ファイル)、「見つからない」結果は 30 分間、`~/Library/Caches/io.github.lanstheprodigy.ririku` にキャッシュされます。設定と曲ごとのオフセットは Ririku の環境設定に保存され、オフセットには調整した曲の動画 ID が含まれます。

## 既知の制限

- 対応しているのは Google Chrome の YouTube と YouTube Music のみです。Apple Music、Spotify、Safari、その他のブラウザには未対応です。
- 拡張機能は「パッケージ化されていない拡張機能を読み込む」でインストールするため、自動更新されません。
- Apple の公証を受けていないため、初回起動時に確認が必要です。
- 歌詞の有無とタイミングは LRCLIB に依存します。
- YouTube のページが変更されると、Ririku が更新されるまで検出できなくなることがあります。
