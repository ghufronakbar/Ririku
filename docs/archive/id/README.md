# Archive: original planning documents (Indonesian)

These documents were written in Indonesian while Ririku was a private prototype (named Notch Box at the time), from the first plan up to v0.3.0. They record the original product brief, design proposals, validation notes, and the reasoning behind early decisions.

They are kept for history and are **no longer maintained**. Some sections describe proposals that were later changed. For current information, use:

- [README](../../../README.md) and the [user guide](../../user-guide.md)
- [Developer documentation](../../development/README.md)
- [Decision log](../../decisions.md)
- [Changelog](../../../CHANGELOG.md)
